This is a template page. It shows every visual anchor the course site uses, so you can write new topic pages in the same structure quickly. Copy this file, give it a new name and replace the text.

Key points
  • Every page opens with a short intro of two or three sentences
  • A key points box summarises what you know or can do after this page
  • Sections get an h2, subsections an h3
  • Callouts mark a tip, a fact or a warning
  • Procedures go in a numbered list of steps

A regular section

Body text is set in Alegreya. Keep paragraphs short. Terms you use for the first time go in bold; literal names of buttons, files or properties go in code.

A subsection

Use lists for parallel items, never for a running argument.

  • First item
  • Second item
  • Third item

Callouts

There are three kinds of callouts. Use at most one or two per section.

Tip

A tip gives practical advice that makes the work easier.

Did you know

A fact gives background or context that is not strictly needed, but enriches.

Watch out

A warning points out a common mistake or pitfall.

Step by step

Put a procedure in a numbered list with the class stappen.

  1. Describe the first step in one sentence.
  2. Describe the second step. Add a short explanation if needed.
  3. Close with what the result should be.

Example

A framed example block for an image, sketch, prototype or case. Put images in the assets/ folder.
